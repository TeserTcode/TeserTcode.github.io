Hofstadter Butterfly — Harper's equation

This viewer uses a transfer-matrix spectral test for the almost-Mathieu / Harper model (λ=1). For each (φ, E) we compute the monodromy trace for a periodic approximation p/q and check |tr| ≤ 2 across sampled Bloch phases k. The pixel color encodes how close the point is to the band.
Notes: the viewer approximates irrational flux by best rational with denominator ≤ q_max. Increasing q_max and kSamples improves accuracy but costs CPU. Try smaller canvas sizes for quick previews.
