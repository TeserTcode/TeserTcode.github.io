Notes: image is treated as grayscale matrix with values in [0,1]. It is padded with zeros to make a square. The matrix inverse is computed via Gauss–Jordan; if singular, a small ε is added to diagonal (Tikhonov) when auto-regularize checked. Output is normalized (divided by max absolute) so determinant not required.
